# Simone Crypto Exercises

## Overview
This repository is my learning journey in theoretical and practical cryptography, created in preparation for the **Forensisch Onderzoeker Cryptografie** position at NFI (Nederlands Forensisch Instituut).

## Repository Structure

### 📚 `/coursera-notes`
Notes, exercises, and materials from Coursera cryptography courses. This includes theoretical foundations, algorithms, and key concepts in modern cryptography.

### 🛠️ `/tools`
Cryptographic tools, scripts, and utilities developed or studied during my learning process. This may include implementations of cryptographic algorithms, analysis tools, and helper scripts.

### 🚀 `/projects`
Hands-on cryptography projects that demonstrate practical applications of cryptographic concepts. These projects showcase problem-solving skills and real-world implementations.

### 🔍 `/forensics`
Forensic cryptography exercises and case studies. This section focuses on cryptographic analysis, reverse engineering, and forensic investigation techniques relevant to the NFI role.

## Goals
- Build a strong theoretical foundation in cryptography
- Develop practical skills in cryptographic implementation and analysis
- Gain expertise in forensic cryptography investigation
- Prepare comprehensively for the Forensisch Onderzoeker Cryptografie role at NFI

## Progress
This repository will be continuously updated as I progress through courses, complete projects, and expand my cryptographic knowledge.
